# Правила работы в этом каталоге

- Работай только внутри этого каталога. Ничего за его пределами не читай и не меняй.
- Запускай тесты командой: `python3 -m unittest -q test_calc.py`.
- Меняй только `calc.py`; тесты не трогай, не удаляй и не ослабляй.
- Не используй `rm`, `git reset`, `sudo`, сетевые команды.
- После работы обнови `PLANPR.md` (цель, решения, ограничения, следующий шаг) и `LOGPR.md`
  (таблица: дата, действие, команда/тест, результат).
- В `LOGPR.md` записывай только фактически выполненные команды и реальные результаты.
  Если тесты не прошли — так и напиши, с фактическим выводом.
- Дату для `LOGPR.md` бери только из команды `date +%F`. Не выдумывай и не угадывай дату;
  если команда не выполнялась — оставь поле даты пустым.
