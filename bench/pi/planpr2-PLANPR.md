# PLANPR.md

## Цель

Исправить ошибки деления на ноль в calc.py для функций percent() и average().

## Архитектурные решения

- В `percent(part, whole)`: добавить проверку `if whole == 0: return 0.0`
- В `average(values)`: добавить проверку `if not values: return 0.0`

## Известные ограничения

Тесты не изменяются и не ослабляются.

## Следующий шаг

Запускать тесты для проверки корректности работы.
